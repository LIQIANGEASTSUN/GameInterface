# GameInterface

跨项目的底层接口与数据契约仓库。

## 职责与边界

- 为 [GameHub](../GameHub/README.md)、[GameSDK](../GameSDK/README.md) 及上层通用框架提供跨项目的底层接口与数据契约，可由 Hub、SDK 或具体项目实现。
- 接口来自已明确的通用需求，不要求先有多个项目或消费者，也不预造潜在接口。
- 契约不泄露厂商 API、实现库类型或专属配置，不包含具体游戏的业务与数据规则。

## 依赖与接入

- 只依赖契约所需的通用基础类型，不反向依赖 Hub、SDK 或宿主项目实现，不形成循环。
- 简单接口及配套数据契约直接放在包根目录；实现方遵守接口约定，消费者默认只依赖所需接口与数据契约。
- 具体接口、配置、生命周期与用法由对应需求及 Task 规定，不能用某套源码或测试补齐规则。与其他包的组合约定见 [GameHub 组合使用](../GameHub/README.md#组合使用)。

## 文档组织

功能模块就近以 `Docs/需求.md` 为入口，直接导航 `Docs/Tasks/<具体交付>.md`；需求显式引用本文及适用规范，Task 继承这些约束并补充必要依赖。
